# Flutter E-Commerce UI

A modern e-commerce mobile app built with Flutter and Dart.

## Features
- Product listing with grid view
- Search bar
- Category filter (Electronics, Sports, Fashion)
- Favourite toggle
- Shopping cart with item count
- Cart total calculation
- Clean Material Design 3 UI

## Getting Started

flutter pub get
flutter run

## Project Structure

lib/main.dart - App entry point
lib/models/product.dart - Product data model
lib/screens/home_screen.dart - Main product listing
lib/screens/cart_screen.dart - Shopping cart
lib/widgets/product_card.dart - Reusable product card
pubspec.yaml - Dependencies

## Technologies
- Flutter 3
- Dart
- Material Design 3
