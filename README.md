# Flutter E-Commerce UI

A modern, fully functional e-commerce mobile application
built with Flutter and Dart.

## Features

- 🛍️ Product listing with grid view
- 🔍 Search bar for finding products
- 🏷️ Category filter (Electronics, Sports, Fashion)
- ❤️ Favourite/wishlist toggle
- 🛒 Shopping cart with item count badge
- 💰 Cart total calculation
- 📱 Clean Material Design 3 UI
